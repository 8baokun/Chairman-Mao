# Chapter 3：第二卷（1937–1941）论持久战、游击战与新民主主义理论

## Core Idea
第二卷把"实事求是+矛盾分析"用于民族战争与建国方略：用**论持久战**驳"亡国论/速胜论"、给出以弱胜强的三阶段曲线；用**新民主主义理论**回答"中国革命走什么路、建什么国"，提出武装斗争/统一战线/党的建设"三大法宝"。这是从"怎么打"到"建什么国"的跃迁。

## Frameworks Introduced
- **论持久战·三阶段模型**：
  - ① 战略防御（敌攻我守、保存实力）→ ② 战略相持（敌我平衡、消耗战游击战）→ ③ 战略反攻（我强敌弱、决战）。
  - 核心判断："抗日战争是持久战，最后胜利是中国的"——基于敌小我大、敌退步我进步、敌寡助我多助。
  - 兵民是胜利之本；战争的伟力"最深厚的根源存在于民众之中"。
  - 反对两种错误：亡国论（只看到敌强）、速胜论（只看到我大）。
- **抗日游击战争的战略问题**：在统一战线正面战场之外，游击战不是战术配角而是**战略**（无后方作战、主动灵活、建立根据地、发动民众）。
  - 主动性、灵活性、计划性三原则。
- **《共产党人》发刊词·三大法宝**：统一战线、武装斗争、党的建设——"正确地理解了这三个问题及其相互关系，就等于正确地领导了全部中国革命"。
- **中国革命和中国共产党 / 新民主主义论·建国纲领**：
  - 革命两步走：民主主义革命→社会主义革命。
  - 新民主主义政治：无产阶级领导的、几个革命阶级联合专政的民主共和国（国体：各革命阶级联合专政；政体：民主集中制）。
  - 新民主主义经济：节制资本、平均地权、"耕者有其田"。
  - 新民主主义文化：民族的、科学的、大众的文化。

## Key Concepts
- **持久战**：敌强我弱时避决战、以空间换时间、积小胜为大胜。
- **亡国论 / 速胜论**：两个极端错误判断，都要反对。
- **三大法宝**：统一战线、武装斗争、党的建设。
- **两步走**：民主主义→社会主义，不能"毕其功于一役"。
- **基本的三角形**：政治（国体政体）+经济+文化 三位一体纲领。

## Mental Models
- **画力量对比的时间曲线**：判断胜负不看此刻强弱，看"强弱对比能否、如何转化"（持久战曲线）。
- **把民众当力量源**：胜利不在武器而在"兵民"，动员民众是战略。
- **法宝清单**：做大事先配齐"联盟+枪杆子+核心组织"三件套。

## Anti-patterns
- **亡国论**：只算静态敌强，忘了矛盾转化与持久积累。
- **速胜论**：低估敌人、高估自己，企图一战定局。
- **毕其功于一役**：混淆两步走，在民主主义阶段强行社会主义。

## Worked Example
论持久战对"亡国论"的反驳：对方说"日本强、中国弱，必亡"。毛泽东拆成四个维度——敌小国/我大国、敌退步/我进步、敌寡助/我多助——证明强者有其脆弱、弱者有其生长点，故"持久"中强弱转化，结论"最后胜利是中国的"。方法示范：用多维度矛盾结构替代单维强弱表。

## Key Takeaways
1. 以弱抗强走持久战：承认弱、拉长时间、积小胜改对比。
2. 游击战在敌后也是战略，靠主动灵活+根据地+民众。
3. 领导革命抓三件套：统一战线、武装斗争、党的建设。
4. 建国先定纲领：政治（联合专政/民主集中）+经济（节制资本/均地）+文化（民族科学大众）。
5. 革命分两步，不能跳步；民主主义阶段不强行社会主义。
