# Chapter 7：第四卷（1949）进城与建国

## Core Idea
革命胜利前夕，毛泽东把视线从"夺取政权"转到"执掌政权"：用**七届二中全会报告**预警骄傲与变质、宣布工作重心由乡村转城市；用**论人民民主专政**回答"建什么国、靠谁专政"；用**党委会的工作方法**给执政骨干一套可操作的组织规程。是从"打天下"到"治天下"的方法交接。

## Frameworks Introduced
- **在七届二中全会上的报告·两个务必 + 重心转移**：
  - **两个务必**：务必使同志们继续地保持谦虚、谨慎、不骄、不躁的作风；务必使同志们继续地保持艰苦奋斗的作风。
  - 工作重心由乡村移到城市，由军事斗争转到**生产建设**。
  - 进城后两个基本矛盾：工人阶级同资产阶级；中国同帝国主义。
  - 告诫防止"四种情绪"：骄傲、以功臣自居、停顿享乐、贪图享受（资产阶级"糖衣炮弹"）。
- **论人民民主专政·国家学说**：
  - 总结40年经验："总结我们的经验，集中到一点，就是工人阶级（经过共产党）领导的以工农联盟为基础的人民民主专政。"
  - 对人民内部实行民主，对敌人实行专政；二者结合即人民民主专政。
  - "枪杆子里面出政权"是历史的结论；人须有"人大"才有发言权。
  - 外交政策基调：另起炉灶、打扫干净屋子再请客、一边倒（独立自主、不承认旧条约）。
- **党委会的工作方法·十二条**（执政组织规程）：
  1. 党委书记要善于当"班长"（带班子）
  2. 把问题摆到桌面上来（不背后）
  3. 互通情报（委员间沟通）
  4. 不懂得不了解的要问下级、问群众（不耻下问）
  5. 学会"弹钢琴"（统筹主次、协调各方）
  6. 要"抓紧"（抓到底、抓具体）
  7. 胸中有"数"（基本统计、主要百分比）
  8. 安民告示（开会前发通知/议程）
  9. 精兵简政（会议/文件简短）
  10. 注意团结那些和自己意见不同的同志
  11. 力戒骄傲（大事因骄败）
  12. 划清两种界限（革命/反革命、成绩/缺点）

## Key Concepts
- **两个务必**：执政前的防腐预警，治天下的作风底线。
- **人民民主专政**：对人民民主+对敌人专政的国体。
- **工作重心转移**：从农村/打仗→城市/生产。
- **弹钢琴**：领导统筹主次、兼顾各方的艺术。
- **胸中有数**：决策要有基本统计与百分比，反对"大概齐"。

## Mental Models
- **进城先防糖衣弹**：胜利后最大风险是骄傲与享乐，用"两个务必"常念。
- **当班长不当家长**：一把手带班子靠民主集中，不独断。
- **弹钢琴式统筹**：抓中心工作的同时照顾一般，不能单打一。

## Anti-patterns
- **骄傲自满 / 功臣自居**：胜利后最易生的病，导致决策失误、脱离群众。
- **只抓中心不顾一般**：单打一、顾此失彼，整体失调。
- **胸中无数**：不摸底、凭印象拍板，犯错误。

## Worked Example
"弹钢琴"：党委抓生产建设这个中心，同时必须兼顾土改、肃反、统战、宣传、党建等"键"，十个指头协调按，单敲一个则其余荒废。方法示范：领导不是只盯一件大事，而是以中心带全局、两面兼顾。

## Key Takeaways
1. 胜利后首防骄傲享乐，"两个务必"是治天下的作风底线。
2. 工作重心转城市、转生产；学会管理城市与经济。
3. 国体=人民民主专政：对人民民主、对敌人专政。
4. 党委会十二条是执政组织规程：班长/摆桌面/弹钢琴/胸中有数/力戒骄傲。
5. 外交独立自主：不承认旧约、打扫屋子再请客。
