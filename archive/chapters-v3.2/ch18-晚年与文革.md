# Chapter 18：晚年与"文化大革命"（1962–1976）

## Core Idea
晚年的毛泽东以"阶级斗争为纲"观察一切，从社会主义教育运动走到"文化大革命"，并把文艺领域作为突破口；他在反修防修的主观愿望与对形势的误判之间，留下了极其复杂、代价深重的晚年篇章——理解它须放回"怕出修正主义"的危机意识中。

## Frameworks Introduced
- **社会主义教育运动 / "四清"（1963 起）**：杭州会议形成"前十条"，强调"阶级、阶级斗争，社会主义教育，依靠贫下中农，四清，干部参加生产劳动"；毛泽东写"人的正确思想是从哪里来的？"作前言，突出"实践是检验真理的唯一标准"。
  - When to use：基层组织涣散时，用"说服教育、洗手洗澡、轻装上阵、团结对敌"而非打倒一片。
- **以阶级斗争为纲**：中央文件首次在"后十条"使用此提法；文艺两个批示把问题看得"十分严重"，成为文革突破口。
- **抓革命，促生产**：毛泽东的核心逻辑——"不搞阶级斗争，人的精神面貌不能振奋，还是搞不好生产"。
- **三个伟大革命运动**："阶级斗争、生产斗争和科学实验，是建设社会主义强大国家的三项伟大革命运动"。

## Key Concepts
- **《人的正确思想是从哪里来的？》（1963）**：哲学名篇，两个飞跃说，"这次飞跃（由精神到物质）比起前一次更伟大"——突出实践检验。
- **文艺工作两个批示（1963–1964）**：称文联协会"十五年来……基本上不执行党的政策，做官当老爷……竟然跌到了修正主义的边缘"。
- **发动"文化大革命"（1966）**：以意识形态/文艺为突破口，全面夺权、红卫兵运动、斗批改。
- **八届十二中全会到九大（1969）**：林彪被确立为接班人。
- **林彪事件（1971）**：九一三事件，接班人出走坠亡，对毛泽东是巨大打击。
- **1972 年内政外交**：尼克松访华、中日建交、重返联合国——晚年外交的显著成就。
- **逝世（1976.9.9）**：时代落幕。

## Mental Models
- **从蚂蚁看阶级**："大踏步走路看不见蚂蚁，一蹲下去就看见了"——警惕忽视阶级斗争的倾向，但也易走向"到处找蚂蚁"。
- **怕出修正主义**：晚年一切部署的底层焦虑——Use X when Y：理解其决策须先理解"防复辟"的危机感。
- **不伤人、分步骤**：即便在严酷运动中，他也三令五申"不要性急、不要搞乱了、不抓辫子不打棍子不戴帽子"。

## Anti-patterns
- **阶级斗争扩大化**：把人民内部矛盾当敌我矛盾，打击面过宽、混淆两类矛盾。
- **以文艺/意识形态为唯一突破口**：把复杂社会矛盾压缩到"封资修"艺术，误判全局。
- **信任个别、打倒多数**：文革中"全面夺权""打倒一切"，破坏了此前"团结大多数"的原则。
- **凭批示定路线**：两个批示以个人判断替代制度安排，缺乏纠偏机制。

## Worked Example
1963 年杭州会议，毛泽东主持起草农村社教"前十条"，并在前言中写下哲学名篇《人的正确思想是从哪里来的？》："人的正确思想，只能从社会实践中来……一个正确的认识，往往需要经过由物质到精神、由精神到物质……多次的反复，才能够完成。"他同时把阶级斗争比作"蚂蚁"，说大踏步走路看不见、一蹲下就看见——既提醒别忽视矛盾，也埋下"到处找蚂蚁"的隐患。两年后（1964）他对文艺工作的第二个批示称协会"十五年来……竟然跌到了修正主义的边缘"，传记点评："看了毛泽东的这个讲话，读了他的这两个批语，人们也就不难理解，他为什么会把文艺问题作为发动'文化大革命'的突破口。"——展现"防修焦虑→文艺突破口→文革"的逻辑链。

## Key Takeaways
1. 晚年主线是"怕出修正主义"的危机意识，理解其决策须放回这一语境。
2. "四清"与《人的正确思想是从哪里来的？》本身有精辟处，但被"以阶级斗争为纲"推向扩大化。
3. 文艺两个批示是文革的突破口，暴露"以意识形态判全局"的误判。
4. 外交上 1972 年打开中美、中日、重返联合国，是晚年少有的亮色；林彪事件与文革代价则极为深重。
