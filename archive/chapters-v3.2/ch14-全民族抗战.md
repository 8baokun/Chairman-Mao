# Chapter 14：全民族抗战（1937–1945）

## Core Idea
抗日战争是毛泽东把"独立自主的持久战"与"最广泛的统一战线"结合到极致的时期：他既敢于第一时间喊出全民族抗战口号、又坚持统一战线中的独立自主，并在整风与七大把全党思想统一到"实事求是"。

## Frameworks Introduced
- **《论持久战》的战略叙事（1938）**：卢沟桥事变次日即判断"中华民族已处在生死存亡的关键时刻"，提出"平津危急！华北危急！中华民族危急！只有全民族实行抗战，才是我们的出路"。
  - When to use：在局势未明时，率先提出能被全国人民一致行动的具体政治口号，以此实现政治领导。
- **统一战线中的独立自主**：既促蒋"建立全国抗战之最后决心"，又"自己真正地准备一切抗日救亡步骤，并同南京一道去做"；反对对国民党"只团结不斗争"或"只斗争不团结"两种极端。
- **整风运动（1942 起）**：反对主观主义、宗派主义、党八股，"惩前毖后，治病救人"，统一全党思想。
- **七大与毛泽东思想**：1945 年七大确立毛泽东思想为党的指导思想；实事求是、群众路线、独立自主被概括为"毛泽东思想的活的灵魂"三个基本点。

## Key Concepts
- **十二月会议到六中全会（1937–1938）**：在党内统一对统一战线与抗战路线的认识。
- **《论持久战》三阶段**：防御、相持、反攻——以时间换空间、以空间换敌人的消耗。
- **《联合政府》主张（1945）**：七大政治报告，提出废止国民党一党专政、建立民主联合政府。
- **思想建党**：整风使全党在"不左不右"的实事求是路线上达成共识。

## Mental Models
- **先发口号、掌握领导权**：不在局势模糊时犹豫，第一时间给出全国人民能行动的目标——Use X when Y：大变局当前，谁先提出具体目标谁就领导。
- **持久就是战略**：弱者对抗强者，靠正确节奏与耐心拖垮对方，而非速胜幻想。
- **又联合又独立**：统战不是交出自主权，而是在合作中保有自己的方向与阵地。

## Anti-patterns
- **对日媾和幻想**：国民党一度想把卢沟桥事变限为"地方事件"——错判民族危机的紧迫性。
- **关门主义/投降主义两端**：只团结或只斗争都错，正确态度是"既不是只有团结，也不是只有斗争"。
- **党八股**：空话连篇、不解决问题的文风，整风明令反对。

## Worked Example
1937 年 7 月 8 日（卢沟桥事变次日），中共中央率先通电："平津危急！华北危急！中华民族危急！只有全民族实行抗战，才是我们的出路。"许多人一时还看不清是日本全面进攻还是地方事件，毛泽东和中共中央却立刻判断"只有全民族团结抗战，才是中国生存和发展的唯一出路"。七月十四日内部指示定下总方针两面："一面促成蒋氏建立全国抗战之最后决心；一面自己真正地准备一切抗日救亡步骤；并同南京一道去做。"传记点评："这是根据历史发展进程提出的基本政治口号……中国共产党如果不能及时地提出这种具体目标，是谈不上政治领导的。"——示范了"早判断+先口号+自主准备"的领导术。

## Key Takeaways
1. 危机时刻先抛出全国人民能一致行动的具体口号，政治领导由此确立。
2. 持久战是弱者对抗强者的正路：不图速胜，以阶段与节奏消耗敌人。
3. 统一战线中必须独立自主，团结与斗争两手都要硬。
4. 整风统一思想、七大确立实事求是，是组织与思想建设的根本一招。
