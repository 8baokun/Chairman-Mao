# Chapter 9：专题·实事求是·调查研究

## Core Idea
"实事求是"是毛泽东思想的精髓，而它的**操作入口是调查研究**。本章把"从实际出发—调查研究—形成规律—回到实践"串成一条可执行链路：没有调查就没有发言权，情况明才能决心大。是一切决策的方法前提。

## Frameworks Introduced
- **实事求是三要素（'实事'→'是'→'求'）**：
  - '实事'：客观存在的一切事物（先承认事实，不凭愿望）。
  - '是'：客观事物的内部联系即规律性。
  - '求'：我们去研究（主动找规律，不坐等）。
  - 合一：从实际出发、研究出规律、再指导行动（见 Ch02 实践论）。
- **调查研究七法（反对本本主义 + 农村调查序言）**：
  1. 开调查会（每次三五人至七八人，找深切了解情况的）
  2. 亲自出马（凡担负领导责任者必须自己调查，不能假手于人）
  3. 典型调查——"解剖麻雀"（抓一个典型弄清一类）
  4. 蹲点深入基层、甘当小学生
  5. 口问手写、亲记亲算
  6. 穷根究底、不求表面
  7. 旁证对比、判别真伪（去粗取精、去伪存真、由此及彼、由表及里）
- **调查—决策—再调查循环**：情况明→决心大→方法对；执行中再调查修正。
- **反对本本主义三句**："没有调查，没有发言权""调查就像十月怀胎，解决问题就像一朝分娩""中国革命斗争的胜利要靠中国同志了解中国情况"。

## Key Concepts
- **实事求是**：从实际出发求规律，全书的方法核心。
- **本本主义**：唯书唯上、不调查，教条主义别名。
- **解剖麻雀**：通过典型弄清一般，调查研究的基本术。
- **去粗取精、去伪存真、由此及彼、由表及里**：整理材料的十六字诀。
- **情况明才能决心大**：调查是决策的前提，不明则乱。

## Mental Models
- **先沉下去再开口**：任何判断前先问"我调查过吗"，没调查就是本本。
- **解剖一只麻雀**：不用普查全局，抓一个典型深挖即可类推一类。
- **用十六字诀炼材料**：拿到一堆材料先去伪存真、由表及里再下结论。

## Anti-patterns
- **本本主义**：捧书本/文件当真理，不结合本地实际。
- **走马观花**：调查只听汇报、看门面，得假情况。
- **情况不明决心大**：不摸底就拍板，必乱必错。

## Worked Example
寻乌调查（1930）：为弄清"对待中间阶级"政策，毛泽东亲自在寻乌开了十几天的调查会，把县城店铺、地主、农民、商人逐一盘清，得出"限制富农、保护中小商人"的具体政策。方法示范：典型调查不是泛泛问，而是把一类人的经济结构"解剖"清楚再定策。

## Key Takeaways
1. 实事求是=承认事实→找规律→指导行动，是全书方法核心。
2. 调查七法：调查会、亲自出马、解剖麻雀、蹲点、口问手写、穷根、旁证。
3. 没有调查就没有发言权；本本是教条不是真理。
4. 材料先过十六字诀（去伪存真、由表及里）再结论。
5. 情况明→决心大→方法对，且执行中再调查修正。
