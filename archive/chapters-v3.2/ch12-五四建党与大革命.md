# Chapter 12：五四·建党·大革命（1918–1927）

## Core Idea
从五四运动到大革命失败，毛泽东完成"从思想家到组织者"的关键转折：他认定力量在农民、在同盟军，并用一篇篇调研式文章把抽象阶级分析落到中国土地，奠定了"到何处寻找力量"的根本答案。

## Frameworks Introduced
- **阶级分析定位同盟军**：《中国社会各阶级的分析》（1925）明确反对两种倾向——陈独秀只联国民党而"忘记农民"（右倾）、张国焘只做工人运动也"忘记农民"（左倾）；指出自耕农、半自耕农、半益农、贫农、雇农"都是我们真正的朋友"。
  - When to use：任何统一战线或动员策略，先画清"谁是我们的敌人、谁是我们的朋友"这张图。
- **用脚做调查、用十四件大事立论**：《湖南农民运动考察报告》（1927，两万余字）以"十四件大事"证明农民运动是革命的正当行动，"好得很"。
  - When to use：当一种社会力量被主流轻视，亲自下去、用具体事例而非口号去证成。
- **把国际刊物当出口**：该报告被共产国际机关刊物《共产国际》译发，是毛泽东第一篇被介绍到国外的文章。

## Key Concepts
- **《湘江评论》"民众的大联合"**：毛泽东指出"民众联合的力量最强"，被《每周评论》（胡适主编）誉为"眼光很远大，议论也很痛快"的重要文字。
- **湖南自治**：主张"每五万人中产生一个"代表的直接平等选举，以"人民宪法会议"制定宪法——早期对"自下而上"治理的探索。
- **农民运动讲习所**：1927 年毛泽东任常务委员并负实际主持之责，培养农运骨干。
- **"好得很"vs"糟得很"**：对农民革命两种评价的根本分野，毛泽东坚决站在"好得很"。

## Mental Models
- **到农民中找主力**：当城市与上层路线受挫，转向最广大的底层——Use X when Y：主流同盟不稳时，去数"真正的朋友"有多少人。
- **调查即武器**：写文章前先下乡，用可核实的事实压倒偏见。
- **组织化的思想**：办刊、办所、建会，把观点变成可持续的动员结构。

## Anti-patterns
- **只联上层忘底层**：陈独秀式右倾——把革命寄托于现成势力而忽视工农，终致力量无源。
- **空论而不调查**：对农民"糟得很"的指责，源于未亲见；不调查就下判断必错。
- **关门主义**：排斥可联合的同盟军，自己孤立自己。

## Worked Example
1927 年毛泽东写《湖南农民运动考察报告》，不靠书房推演，而是实地走遍湘潭等五县。报告列"十四件大事"，断言农民"攻击的形势，简直是急风暴雨，顺之者存，违之者灭"，把几千年封建地主特权"打得个落花流水"，并明确主张"推翻地主武装，建立农民武装"。这篇以事实立论的报告被共产国际俄文、英文版翻译发表，英文编者按称"在迄今为止的介绍中国农村状况的英文版刊物中，这篇报道最为清晰"——示范了"调查→事实→国际传播"的完整打法。

## Key Takeaways
1. 革命的第一个问题永远是"谁是我们的朋友"——阶级分析是定位同盟军的方法，不是标签游戏。
2. 农民是中国革命最深厚的力量来源，轻视即失去根本。
3. 重大主张必须用实地调查支撑，方能经得起反驳与国际传播。
4. 思想要组织化（刊物、讲习所、学会）才能转化为运动。
