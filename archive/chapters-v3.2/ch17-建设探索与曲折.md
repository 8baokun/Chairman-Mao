# Chapter 17：建设道路的探索与曲折（1956–1966）

## Core Idea
苏共二十大后，毛泽东提出"以苏为鉴"、走自己的路，产出《论十大关系》《关于正确处理人民内部矛盾的问题》等自主建设纲领；但随后"大跃进""人民公社"急于过渡，他又以两次郑州会议自我纠偏——展示了探索者的勇气，也留下"敢想敢干"越过客观法则的深刻教训。

## Frameworks Introduced
- **《论十大关系》（1956）"以苏为鉴"**：历时 37 天听 34 个部门汇报后归纳，"我们一定要努力把党内党外、国内国外的一切积极的因素……全部调动起来，把我国建设成为一个强大的社会主义国家"。
  - When to use：搞建设前先做系统调查，拿本国情况同别国经验对照，找自己的路。
- **"双百"方针（1956）**："艺术问题上的百花齐放，学术问题上的百家争鸣"；主张在宪法范围内"各种学术思想，正确的、错误的，让他们去说"。
- **《关于正确处理人民内部矛盾的问题》（1957）**：把敌我矛盾与人民内部矛盾分开，用"团结—批评—团结"处理内部矛盾。
- **两次郑州会议纠"左"（1958–1959）**：第一次郑州会议划清社会主义/共产主义界限、肯定商品生产；第二次郑州会议点破"一平、二调、三收款"的共产风，承认"瞒产私分基本合法"。
  - When to use：运动失控时，亲下基层调查、从所有制根子上纠偏，而非压指标了事。

## Key Concepts
- **北戴河会议高指标（1958）**：定钢 2700–3000 万吨、急于"跑步进入共产主义"，是冒进顶点。
- **压缩空气（武昌会议）**：钢指标从 3000 万吨降到 1800 万吨，"把脑筋压缩一下，把空气变成固体空气"。
- **一平二调三收款**：穷富拉平、积累过多、无偿上调生产资料、银行收贷——引发农民恐慌的"共产风"。
- **《关于读书的建议》（1958）**：毛泽东倡议读斯大林《苏联社会主义经济问题》《马恩列斯论共产主义社会》以"获得清醒的头脑"。
- **七千人大会（1962）**：总结大跃进教训，初步纠偏。
- **中苏论战（1963–1964）**：九评苏共公开信，国际共运路线之争。

## Mental Models
- **调查像"十月怀胎"，解决问题像"一朝分娩"**：先系统调研再决策——Use X when Y：面对陌生复杂系统，用 34 部门式调查换清醒。
- **敢想敢干但别破科学**："凡迷信一定要破除，凡真理凡科学一定要保护"——冒进的边界是客观法则。
- **从"瞒产私分"读出所有制问题**：表象之下找制度根子，而非惩罚表象。

## Anti-patterns
- **盲目赶超苏联**："当奴隶当惯了，总是有点奴隶气，好像《法门寺》里的贾桂"——丧失独立自主的判断。
- **急于过渡/取消商品**：把公社当全民所有制、急于"进入共产主义"，混淆阶段、违反经济法则。
- **浮夸与作假**："扫盲半年扫光""绿化年年化"——上层信假，危险在"前三级都相信"。
- **一个脑袋过热**：高指标来自"想把钢铁搞得越多越好"的主观愿望，需靠实践降温。

## Worked Example
1958 年"大跃进"中，毛泽东发现农村普遍"瞒产私分"、闹粮荒。他带问题南下调查：在天津、济南、郑州同省地县干部座谈，逐渐点破"瞒产是有原因的，怕'共产'，怕外调。农民拼命瞒产是个所有制问题。本位主义是怕调，这种本位基本上是对的"。第二次郑州会议上他明确："目前同农民关系中最根本的问题"是"一平、二调、三收款"引起的恐慌，批评领导者"误认人民公社一成立……就可以由公社领导机关直接支配"生产队财产。从"赞成反本位主义"到"支持保守主义、站在右派一方面"，这一转变"来自他亲身的调查研究"——是用一线调查修正顶层误判的标本。

## Key Takeaways
1. 建设必须"以苏为鉴"、走自己的路；《论十大关系》是自主探索的纲领性成果。
2. 双百方针与人民内部矛盾学说，是处理文化与政治生活的开创性框架。
3. 冒进的教训：阶段不可跳、商品不可废、客观法则不可破；纠偏要靠亲自调查。
4. 郑州会议证明：顶层错误要由"下到基层、从所有制根上改"来纠正，而非压指标。
