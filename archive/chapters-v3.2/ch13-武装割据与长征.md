# Chapter 13：武装割据·长征·西安事变（1927–1937）

## Core Idea
大革命失败后，毛泽东走出"农村包围城市"的独立道路：在逆境中坚持正确主张、用调查与耐心争取大多数，遵义会议成为"走自己的路"的转折点——这是他后来反复使用的危机领导范式。

## Frameworks Introduced
- **工农武装割据 / 农村包围城市**：在井冈山、赣南闽西建立根据地，提出"星星之火，可以燎原"（1930 年给林彪回信），反对"红旗到底打得多久"的悲观。
  - When to use：当主流路线（中心城市暴动）走不通，转向敌人薄弱、自己能扎根的广阔乡村积蓄力量。
- **在逆境中"一个一个做工作"争取大多数**：长征路上毛泽东同王稼祥、张闻天行军议论，逐一说服，促成遵义会议转折。
  - When to use：身处少数时，不硬拚，而是私下沟通、让正确意见被多数接受。
- **独立自主解决组织问题**：遵义会议依民主集中制，结束王明"左"倾教条主义四年统治，确立毛泽东在党中央和红军中的领导地位。

## Key Concepts
- **古田会议**：1929 年解决党内思想建设与军队建设根本问题，毛泽东紧接思考"对于时局的估量和伴随而来的我们的行动问题"。
- **五次反"围剿"失败**：1931 赣南会议到 1934 长征前，毛泽东被批为"狭隘经验论""富农路线""右倾机会主义"，甚至被剥夺工作权利。
- **遵义会议（1935）**：生死关头独立自主纠错，"走自己的路"，挽救了党和红军。
- **《孙子兵法》插曲**：毛泽东自述当时只看过《三国演义》，并未看过《孙子兵法》，被凯丰"照两本书打仗"的指责逼得后来才翻了《孙子兵法》——反对本本主义。

## Mental Models
- **星星之火可以燎原**：弱小时势看趋势与生根能力，不看来势汹汹——Use X when Y：处于低谷但方向对，先扎根再燎原。
- **办什么事都要有个大多数**：遵义会议后毛泽东感叹"我们欠根据地人民的实在太多了"，更懂团结多数。
- **逆境淬炼**：被孤立的痛苦磨练让他"更加沉着、练达，思想更加缜密、周到，特别是更善于团结人"。

## Anti-patterns
- **本本主义/照书本打仗**：把《三国演义》《孙子兵法》当教条，脱离中国实际必败（王明路线即其极端）。
- **残酷斗争、无情打击**：来自党内的"左"倾打击，会摧毁正确力量；正确做法是严肃批评又热情团结。
- **忽视大多数**：只靠少数精英硬干，缺乏同盟与群众基础。

## Worked Example
长征出发前，毛泽东已被排斥出核心、"弄到于都去搞调查研究"。长征路上他与王稼祥、张闻天同住同行，一路讲反五次"围剿"军事领导错误，逐渐"在政治局内开始了反对李德、博古的斗争"。王稼祥回忆："毛泽东同志开始对我们解释……以马列主义普遍真理和中国革命实践相结合的道理教导我，促使我能够向毛主席商谈召开遵义会议的意见。"遵义会议最终依民主集中制独立自主改组领导、"走自己的路"。会后毛泽东说："办什么事都要有个大多数啊！"——这是"在孤立中靠一对一说服争取多数"的范本。

## Key Takeaways
1. 中心城市路线走不通时，转向农村根据地积蓄力量，是务实的战略转移而非退却。
2. 身处逆境不硬拚，用调查与耐心的私下沟通争取多数，方能实现转折。
3. 独立自主（不照搬苏联/本本）是遵义会议最宝贵的遗产。
4. 对犯错的同志严肃又团结，才能不重演"残酷斗争"的内伤。
