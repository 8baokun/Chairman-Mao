# Chapter 5：第三卷（1943–1945）领导方法与根本宗旨

## Core Idea
这一组回答"党怎么带群众、为谁干"：用**关于领导方法的若干问题**把群众路线写成可操作公式，用**为人民服务**立宗旨，用**论联合政府**把"人民战争路线+三大作风"推向建国政治纲领。是从"思想方法"到"组织方法/价值立场"的闭环。

## Frameworks Introduced
- **关于领导方法的若干问题·两个结合（领导方法公式）**：
  - 一般号召与个别指导相结合：先普遍号召，再抓试点突破、取得经验、推广全局。
  - 领导骨干与广大群众相结合：把积极分子组成领导核心，团结中坚、带动中间。
  - **基本公式**："将群众的意见（分散无系统）集中起来（研究成系统），又到群众中坚持下去、见之于行动，在行动中考验；再从群众中集中，再坚持下去"——即**从群众中来，到群众中去**的无限循环。
- **为人民服务·宗旨四句**：
  - 我们的队伍完全为着解放人民、彻底地为人民的利益工作。
  - 人固有一死，"或重于泰山，或轻于鸿毛"。
  - 为人民的利益坚持好的、为人民的利益改正错的（批评自我批评的落脚点）。
  - 互相爱护、关心、帮助。
- **论联合政府·三大作风**（区别于其他政党的标志）：
  1. 理论和实践相结合的作风
  2. 和人民群众紧密地联系在一起的作风
  3. 自我批评的作风
  - 政治路线：放手发动群众、壮大人民力量，在我党领导下打败侵略者、解放全中国。

## Key Concepts
- **从群众中来，到群众中去**：领导认识来自群众、回到群众检验。
- **一般号召与个别指导**：先动全局、再抓试点、后推广。
- **三大作风**：理论联系实际、密切联系群众、自我批评。
- **宗旨**：共产党及其军队的存在理由=为人民服务。

## Mental Models
- **集中—坚持循环**：凡推行政策，先下沉收集分散意见→研究成方案→回群众试行→再收集修正，循环上升。
- **先试点后铺开**：新举措抓一两个点取得经验，再一般号召全面推。
- **用"为谁"校准一切**：判断一项工作对错，回到"是否人民利益"这一宗旨尺。

## Anti-patterns
- **命令主义 / 尾巴主义**：前者强迫群众超越觉悟，后者落后于群众要求——二者都脱离"从群众中来"。
- **只有号召没有指导**：只发文件不抓试点，政策落不了地。
- **忘宗旨而谋私利**：组织/个人脱离"为人民服务"标尺即变质。

## Worked Example
"一般号召与个别指导相结合"：要推广某政策，先向全区发出号召（一般），同时亲自在一个乡/连队蹲点做出样子、找出具体办法（个别指导），再把经验写成指示推广。方法示范：避免"文件满天飞、下面不会做"——用试点把抽象号召转成可复制做法。

## Key Takeaways
1. 领导方法=两个结合+从群众中来到群众中去。
2. 任何政策先试点取经、再一般号召，避免空转。
3. 宗旨是尺：一切工作以"人民利益"校准。
4. 三大作风是政党成色标志：理论联系群众+联系群众+自我批评。
5. 批评与自我批评落脚在"为人民的利益改正错的"。
