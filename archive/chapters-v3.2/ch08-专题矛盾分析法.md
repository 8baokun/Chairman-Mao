# Chapter 8：专题·矛盾分析法（从《矛盾论》到《关于正确处理人民内部矛盾的问题》）

## Core Idea
矛盾分析是毛泽东全部方法的"总开关"。本专题把分散在各卷的矛盾思想收口成一张**可复用分析清单**：先用《矛盾论》六层看清事物内部，再用《关于正确处理人民内部矛盾的问题》区分"敌我"与"人民内部"两类矛盾、给出不同解法。任何复杂局面都先过这张清单。

## Frameworks Introduced
- **矛盾论六层分析法（操作清单）**：
  1. 判宇宙观：用联系/发展/矛盾的观点，不用孤立静止的。
  2. 找普遍性：此事全程有哪些矛盾？
  3. 辨特殊性：每个矛盾"质"不同，解法不能一刀切（见 Ch01/Ch02）。
  4. 抓主要矛盾与矛盾主要方面：复杂过程全力找主要矛盾；两面分主次定性质。
  5. 看同一性与斗争性：双方如何依存、如何斗争、条件何在、能否转化。
  6. 定对抗形式：是否取对抗（敌我）还是非对抗（人民内部）。
- **两类矛盾区分（《关于正确处理人民内部矛盾的问题》）**：
  - **敌我矛盾**：对抗性，用专政/镇压解决。
  - **人民内部矛盾**：非对抗性，用**民主、说服、教育、"团结—批评—团结"**解决。
  - 公式：从团结的愿望出发，经过批评或斗争，分清是非，在新的基础上达到新的团结。
  - 社会主义基本矛盾：生产关系和生产力、上层建筑和经济基础之间基本适应但局部不适应——靠**制度内自我调节**而非推翻。
- **统筹兼顾、适当安排**：处理人民内部利益矛盾，"统筹兼顾、适当安排"，各得其所。
- **百花齐放、百家争鸣**：艺术科学上"放"与"鸣"，作为正确处理人民内部思想矛盾的方法。

## Key Concepts
- **对抗性 / 非对抗性**：矛盾斗争的两种形式，决定用专政还是民主。
- **团结—批评—团结**：处理人民内部矛盾的固定公式。
- **弹钢琴（矛盾统筹）**：见 Ch07，统筹主次矛盾。
- **基本矛盾自我调节**：社会主义矛盾可在制度内调整，不必外求革命。

## Mental Models
- **先分类再定法**：遇到矛盾先问"这是敌我还是人民内部"，对抗性才用强制。
- **抓主要矛盾**：千头万绪先找"牵一发而动全身"的那一个。
- **用团结收尾**：人民内部的批评只为"新的团结"，不为打倒人。

## Anti-patterns
- **敌我不分**：把人民内部矛盾当敌我、搞专政扩大化 → 伤害自己人。
- **混用解法**：用强制解决思想问题、用说服解决对抗问题 → 都失败。
- **忽视特殊性**：用一种办法套所有矛盾 → 药不对症。

## Worked Example
"团结—批评—团结"：某单位思想分歧，若按敌我处理（开除、批判到底）会压垮积极性；正确做法是阐明"这是人民内部矛盾"，从团结愿望出发开诚布公批评、分清是非，再在新的基础上团结共事。方法示范：先定性矛盾类别，再选对应解法，避免扩大化。

## Key Takeaways
1. 矛盾分析六步是通用清单，复杂问题先逐层过一遍。
2. 矛盾先分"敌我/人民内部"，对抗性才专政、非对抗用民主。
3. 人民内部矛盾公式固定为"团结—批评—团结"。
4. 社会主义矛盾可在制度内统筹兼顾、自我调节。
5. 抓主要矛盾、看主次方面，是"提纲挈领"的操作化。
