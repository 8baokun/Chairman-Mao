# Chapter 16：执掌政权与社会主义改造（1949–1956）

## Core Idea
执政之初，毛泽东以"跳出周期率"为总纲，用最广泛的统一战线团结各界、用民族区域自治保统一、用"边学边干"完成恢复经济与社会主义改造——展示了从革命党到执政党的系统性转身。

## Frameworks Introduced
- **跳出历史周期率（黄炎培之问，1945/1949 后重申）**："我们已经找到新路，我们能跳出这周期率。这条新路，就是民主。只有让人民来监督政府，政府才不敢松懈。只有人人起来负责，才不会人亡政息。"
  - When to use：任何长期执政的组织，都要靠外部监督与人人负责防止懈怠腐化。
- **五湖四海的统一战线**：组建中央人民政府时"共产党人和进步人士一半一半好"，对起义将领"有职有权"，"搞统一战线哪能怕麻烦"。
- **民族区域自治替代民族自决**：建国时决定不搞联邦制而实行民族区域自治，防止帝国主义借"自决"分裂。
  - When to use：多民族国家设计制度，优先团结统一、反对被利用的分离口号。
- **过渡时期总路线 + 和平赎买**：用"利用、限制、改造"和"赎买政策"完成对资本主义工商业的社会主义改造（列宁想干而不能干）。

## Key Concepts
- **第一次访苏（1949–1950）**：建国两月即出访，解决《中苏友好同盟互助条约》等重大问题；苏联照会使毛泽东"情不自禁地同机要秘书握了握手"。
- **抗美援朝（1950–1953）**：决策"打得一拳开，免得百拳来"，确立新中国国际地位。
- **"三反""五反"**：反贪污、浪费、官僚主义与反行贿、偷税漏税等，整肃执政初期风气。
- **新中国第一部宪法（1954）**：以《共同纲领》为基础制定，确立人民民主制度。
- **农业合作化道路**：从互助组到初级社再到高级社，引导个体农民走集体化。

## Mental Models
- **民主是新路**：把"被监督"当制度优势而非负担——Use X when Y：组织变大变久，主动引入监督防周期率。
- **包下来、给出路**：对国民党千万党政军人员"都包起来"，减少社会震荡、广结人心。
- **实事求是答复党外意见**：黄炎培反映征粮偏差，毛泽东即令"有则说有，无则说无，是则是，非则非"实地核查。

## Anti-patterns
- **关门主义**：对民主党派"手掌是肉手背是肉，不能有厚薄"，排斥党外即易生官僚主义。
- **照搬苏联/联邦制**：在多民族中国搞联邦制会被分裂势力利用，必须走民族区域自治。
- **忽视人民来信**：对群众来信"掉以轻心、置之不理"是官僚主义，他严令改正。

## Worked Example
1945 年黄炎培在延安问毛泽东：历代"其兴也浡焉，其亡也忽焉"，中共能否跳出这周期率？毛泽东答："我们已经找到新路……这条新路，就是民主。只有让人民来监督政府，政府才不敢松懈。只有人人起来负责，才不会人亡政息。"建国后他把这落到制度：组建政府"共产党人和进步人士还是一半一半好，要搞五湖四海"；对傅作义"和平起义是有功的，应该让他自己挑一个副部长，有职有权"；每月给程潜五万斤小米补贴，"主席说，程潜应酬多，开销大"。传记评："毛泽东对起义将领说的这一席话，是肺腑之言……把中国共产党所以要实行统一战线的道理，说得非常明白。"

## Key Takeaways
1. 执政的根本考验是跳出周期率——靠民主与人民监督，而非靠个人英明。
2. 最广泛的统一战线（五湖四海、有职有权）是新政权巩固的底层逻辑。
3. 多民族国家用民族区域自治保统一，警惕"自决"被分裂势力利用。
4. 改造讲究"利用、限制、改造"与和平赎买，减少震荡、广结人心。
