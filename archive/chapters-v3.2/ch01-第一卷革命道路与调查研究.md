# Chapter 1：第一卷（1925–1937）革命道路与调查研究

## Core Idea
在敌强我弱、革命陷入低潮时，毛泽东不开"本本"、不赌城市暴动，而是**先调查、再定性**，从中国社会各阶级的真实关系里找出"谁是我们的敌人、谁是我们的朋友"，并在敌人统治薄弱的农村另辟"工农武装割据"之路。第一卷是整套思想的**经验起点与方法起点**。

## Frameworks Introduced
- **阶级分析总框架（谁是我们的敌人？谁是我们的朋友？）**：革命首要问题。
  - 划分：地主买办阶级（反动）→ 中产阶级（动摇）→ 小资产阶级（可争取）→ 半无产阶级（最接近朋友）→ 工业无产阶级（领导力量）。
  - 应用：任何政治研判先画"敌—友—我"三栏，再定联合/孤立策略。
- **工农武装割据**：在四周白色政权中小块红色政权能长期存在的五条件——① 帝国主义间接统治、经济落后、发展不平衡；② 经过民主革命影响的群众；③ 全国革命形势向前发展；④ 有相当力量的正式红军；⑤ 共产党组织的有力量和政策不错误。
  - 三位一体：武装斗争 + 土地革命 + 根据地建设。
- **星星之火，可以燎原**：用"星火→燎原"否定"红旗到底打得多久"的悲观，论证革命高潮的必然性（不是"可望不可即"）。
- **没有调查，没有发言权（反对本本主义）**：反对"本本主义"（教条主义），提出"从斗争中创造新局面"，"调查就像'十月怀胎'，解决问题就像'一朝分娩'"。
  - 七条调查技术：开调查会、亲身出马、深挖到底、口问手写、穷根究底、旁证对比、判别真伪。

## Key Concepts
- **本本主义**：不调查、唯书唯上、把马克思主义当教条。
- **矫枉必须过正**：革命群众运动往往"过正"才能"矫枉"，不能书生气地责备。
- **革命的主观力量**：不在于数量是否多，而在于"质"（能否生长）。
- **半无产阶级**：农民、小手工业者等，革命最接近的朋友。
- **政治路线确定之后，干部就是决定的因素**（后续论断，根在此卷）。

## Mental Models
- **用"敌友我"三栏给复杂局面定性**：任何力量博弈先分敌、友、中间，再定策略。
- **在薄弱处建根据地**：正面强攻不成，转去对手最弱、自己最能生长的缝隙立脚。
- **调查先于结论**：没跑过、没问过，就不开口；结论从材料里长出来。

## Anti-patterns
- **本本主义**：把上级指示或书本当真理，不结合本地实际 → 必然脱离群众、丢失阵地。
- **悲观主义（红旗打多久）**：只看眼前弱小，不懂矛盾转化与高潮必然 → 丧失方向。
- **轻视农村／迷信城市中心**：照搬外国经验，忽视中国"农民为主、发展不平衡"的国情。

## Worked Example
《湖南农民运动考察报告》（1927）：为回应"农运糟得很"的指责，毛泽东用32天实地考察，列出农民做的**十四件大事**（组建农会、打倒土豪、禁烟赌、办合作社等），用事实反驳"糟得很"，提出"矫枉必须过正"。方法示范：不是先有结论再去套，而是先沉下去看、再为运动正名。

## Key Takeaways
1. 革命/任何事业的首要问题是分清敌、友、我。
2. 道路选择服从国情：中国只能"农村包围城市"，不能抄城市中心论。
3. 结论前必须先调查；"本本"不能代替"实情"。
4. 弱小时在敌人薄弱处立根据地，靠"质"的生长而非数量。
5. 悲观源于只看静态力量，不懂矛盾转化与高潮必然。
