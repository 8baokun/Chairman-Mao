# Chapter 15：解放战争与新中国诞生（1945–1949）

## Core Idea
抗战胜利后，毛泽东以"针锋相对，寸土必争"的姿态应对重庆谈判与全面内战，靠集中优势兵力打歼灭战、以战略决战夺取政权，并在七届二中全会完成由"打仗"到"建政"的思维切换。

## Frameworks Introduced
- **针锋相对，寸土必争**：在《抗日战争胜利后的时局和我们的方针》中确立的对蒋方针——不幻想、不放弃武装、以斗争求和平。
  - When to use：面对假和谈真备战对手，边谈边备、以实力换主动。
- **集中优势兵力，各个歼灭敌人**：十大军事原则之首，解放战争歼敌有生力量的核心打法。
- **战略决战的全局调度**：辽沈、淮海、平津三大战役的"日日夜夜"，体现"高屋建瓴、势如破竹"的指挥气概。
- **两个务必（七届二中全会，1949）**："务必使同志们继续地保持谦虚、谨慎、不骄、不躁的作风，务必使同志们继续地保持艰苦奋斗的作风"；宣布"夺取全国胜利，这只是万里长征走完了第一步"。

## Key Concepts
- **重庆谈判（1945）**：毛泽东亲赴重庆，"谈笑间"显露"喜笑怒骂皆成文章"的自信；传记载其读相关文稿时"不时地发出爽朗的笑声"。
- **《论人民民主专政》（1949）**：为新中国建国纲领奠定理论基础与政策基础，"就其基本思想来说，将在长时间内保持它的生命力"。
- **七届二中全会报告**：提出工作重心由乡村转向城市、"先城市后乡村"方式的反转。
- **"战斗队又是工作队"**：1949 年《把军队变为工作队》电报，预判接管大城市需军队转为工作队。

## Mental Models
- **以斗争求和平**：和平不是让出来的，是打出来、谈出来的——Use X when Y：对手只认实力，先有实力再谈。
- **决战就要"势如破竹"**：看准转折点就集中全力，不在局部纠缠。
- **进城先想"退思"**：胜利在即时反而警惕骄傲，七届二中全会把"两个务必"刻进组织基因。

## Anti-patterns
- **把胜利当终点**：毛泽东明确反对"革命到头"思想，强调只是"万里长征第一步"。
- **只谈不备**：对假和谈掉以轻心，会丧失主动权（蒋的"限共"伎俩）。
- **农村惯性**：进城后若仍以农村方式管城市必乱，必须"先城市后乡村"。

## Worked Example
1949 年 3 月七届二中全会上，毛泽东提出"两个务必"，并坦承"夺取全国胜利，这只是万里长征走完了第一步"。他主持审读《毛选》第四卷时"显得特别兴奋，'想当年，金戈铁马，气吞万里如虎'的气概，油然而生"，读到《论人民民主专政》《在七届二中全会上的报告》两篇，认为"为新中国建国纲领奠定了理论基础和政策基础，就其基本思想来说，将在长时间内保持它的生命力"。传记特别点出：第四卷"既有高屋建瓴、势如破竹的气势，又有行云流水、议论风生的韵致"——展示了"战场上的笃定"如何转化为"建政时的清醒"。

## Key Takeaways
1. 对假和谈的对手，针锋相对、以实力促和平是唯一可靠姿态。
2. 集中优势兵力各个歼灭，是弱者转强者的军事公理。
3. 七届二中全会把"两个务必"植入组织基因，防胜利骄傲。
4. 进城即切换思维：从"夺权"转"建政"与"管大城市"。
