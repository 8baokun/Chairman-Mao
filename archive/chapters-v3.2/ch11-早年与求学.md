# Chapter 11：早年与求学（1893–1918）

## Core Idea
毛泽东的思想底色在离家求学、自我教育与早年社会观察中成形：强烈的自主精神、经世致用的实学取向、以及"扎在底层、眼观天下"的信息习惯，是他后来一切战略与文风的根。

## Frameworks Introduced
- **自我教育与"不满足于学校"**：认定方向就敢采取惊世骇俗的行动（断然从湖南全省高等中学校退学，寄居湘乡会馆，每天步行三里到定王台湖南省立图书馆自学）。
  - When to use：当体制化学习无法满足真实求知需求时，优先自建学习系统而非被动接受课程。
- **以天下事为课题**：读《御批历代通鉴辑览》一百一十六卷后更信"在校读书不如自学"，把历史、时局、人物当连续的研究对象。
- **体魄与精神并练**：在《体育之研究》中自编体操（日光浴、风浴、雨浴、冷水浴、游泳、登山、露宿、长途跋涉、拳术），相信"野蛮其体魄"方能支撑长期奋斗。

## Key Concepts
- **二十八画生**：毛泽东 1917 年发表《体育之研究》于《新青年》的署名（"毛泽东"三字繁体共二十八画）。
- **《湘江评论》**：1919 年毛泽东任主编的主要撰稿刊物，全用白话文，"以宣传最新思潮为主旨"。
- **新民学会**：1918 年毛泽东与蔡和森等发起的进步团体，是其最早的组织与思想训练场。
- **文化书社**：1920 年前后毛泽东以"特别交涉员"身份筹办，实为湖南共产主义小组对内对外联络机关。
- **湖南自治运动**：主张"先城市后乡村"方式反转前的务实地方自治探索。

## Mental Models
- **把图书馆当军校**：没有好老师就自己排兵布阵读原典——Use X when Y：当资源受限，用系统性自读替代被动听课。
- **思想是练出来的**：体育、劳作、社会调查都是"淬炼意志"的手段，不只求知识。
- **从乡关到天下**：任何具体问题先放到民族危亡的尺度上衡量（"何以报仇？在我学子！"）。

## Anti-patterns
- **只读不炼**：只吸收知识而不以体魄、实践、组织去转化，易成空谈。毛泽东早年即反对"程朱哲学，没有气，没有长角"。
- **依赖现成答案**：把学校课程、权威结论当终点，会丧失独立判断。

## Worked Example
1917 年《体育之研究》中，毛泽东不仅立论，还"详细介绍了自己编的一套体操"，锻炼项目含日光浴、风浴、雨浴、冷水浴、游泳、登山、露宿、长途跋涉及拳术。同一时期他常和蔡和森、张昆弟讨论宋明理学，研读朱熹《近思录》《四书集注》《朱子语类》，又用陆（九渊）王（守仁）"心即理"视角批注泡尔生《伦理学原理》——体现"读原典+亲身试+自批注"的三合一自学法。

## Key Takeaways
1. 真正的自主学习是"自定课题、自排体系、自求证"，而非等课程。
2. 体魄是长期斗争的底层资源，毛泽东一生坚持冷水浴、游泳。
3. 组织（新民学会）与媒介（《湘江评论》、文化书社）是把思想变成行动的杠杆。
4. 早年"睁眼看世界"的信息习惯（读报、通信、调查）贯穿其一生。
