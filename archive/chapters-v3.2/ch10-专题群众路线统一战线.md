# Chapter 10：专题·群众路线与统一战线

## Core Idea
"靠谁干、团结谁"是毛泽东战略的两根支柱：**群众路线**解决力量来源（人民是历史动力），**统一战线**解决联盟策略（团结多数、孤立少数）。二者共同回答"革命的首要问题——谁是我们的敌人、谁是我们的朋友"，是把矛盾分析用于力量配置的总法。

## Frameworks Introduced
- **统一战线·三问起点**："谁是我们的敌人？谁是我们的朋友？这个问题是革命的首要问题。"
  - 阶级排队：依靠（工人、农民）→ 争取（小资、民族资产阶级等中间势力）→ 孤立（主要敌人及其顽固派）。
  - **三句话策略**：发展进步势力、争取中间势力、孤立顽固势力。
  - **又联合又斗争**：以斗争求团结则团结存，以退让求团结则团结亡。
  - **独立自主**：统一战线中保持政治上组织上的独立，不似奴才。
- **群众路线·总公式**："人民，只有人民，才是创造世界历史的动力"；从群众中来、到群众中去（见 Ch05）。
  - 领导方法两结合：一般号召与个别指导、领导骨干与广大群众（见 Ch05）。
  - **抓两头带中间**：抓先进典型与落后典型，带动中间大多数。
- **同盟军动态管理**：依时期变敌友——抗战时民族矛盾为主、资产阶级可联合；解放战争时阶级矛盾为主、孤立官僚资产阶级。

## Key Concepts
- **首要问题**：分清敌、友、我，是一切策略的前提。
- **中间势力**：可争取可不争取、决定胜负的关键变量，须重点争取。
- **又联合又斗争**：联合中不丧独立、斗争中不破联合。
- **抓两头带中间**：带队伍用典型牵引多数。
- **独立自主**：联盟中不失自我，不为联合出卖原则。

## Mental Models
- **先列敌友我三栏**：任何博弈先排清"靠谁、争谁、孤立谁"。
- **重点争中间**：胜负常不在基本盘，而在中间势力的归向。
- **以斗保联**：想在联盟里不被吃，就得敢斗争、善退让有度。

## Anti-patterns
- **关门主义**：只要纯、不要盟，把中间势力推给敌人。
- **投降主义**：为联合放弃原则、丧失独立。
- **轻视群众**：以为少数精英能包办，脱离力量源泉。

## Worked Example
抗日民族统一战线（1935–37）：民族矛盾上升为主要矛盾，毛泽东及时调整——把"反蒋"转为"逼蒋抗日"、和平解决西安事变、改红军为八路军新四军、实行减租减息以团结地主抗日，但坚持党在统一战线中的独立自主。方法示范：依主要矛盾变化重组敌友，联合中保独立，是"又联合又斗争"的范本。

## Key Takeaways
1. 革命/任何策略首要问题是分清敌、友、我。
2. 统一战线三句：发展进步、争取中间、孤立顽固。
3. 又联合又斗争，以斗争求团结；联合中保独立。
4. 群众路线：人民是动力，从群众中来到群众中去。
5. 敌友随主要矛盾变而变，须动态调整联盟。
