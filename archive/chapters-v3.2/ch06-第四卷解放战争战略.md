# Chapter 6：第四卷（1945–1949）解放战争战略

## Core Idea
第四卷是"以弱胜强"的军事总账：用**集中优势兵力，各个歼灭敌人**定基本战法，用**目前形势和我们的任务**系统化为"十大军事原则"并亮出"打倒蒋介石"的政治目标，用**在晋绥干部会议上的讲话**明确新民主主义革命总路线。是战略藐视、战术重视在实战中的成熟形态。

## Frameworks Introduced
- **集中优势兵力，各个歼灭敌人（基本战法）**：
  - 先打分散、孤立之敌，后打集中、强大之敌。
  - 以歼灭敌人**有生力量**为主，不以保守/夺取城市地方为主。
  - 每战集中绝对优势（两倍、三倍、四倍甚至五倍六倍于敌），四面包围，力求全歼。
  - 运动战为主，在运动中歼敌。
- **目前形势和我们的任务·十大军事原则**（核心条款）：
  1. 先打分散孤立之敌，后打集中强大之敌
  2. 取中程和远距离机动、以歼灭敌有生力量为主要目标
  3. 以集中优势兵力各个歼灭敌人为主要方法（每战优倍于敌）
  4. 不打无准备无把握之仗
  5. 扬我之长（近战夜战）
  6. 发扬勇敢顽强、连续作战
  7. 力求在运动中歼敌
  8. 在守备/攻城上依形势选择
  9. 以俘获补充自己（以战养战）
  10. 善于利用两战役间休整
  - 政治目标并列提出："打倒蒋介石，解放全中国"。
- **在晋绥干部会议上的讲话·新民主主义革命总路线**：无产阶级领导的、人民大众的、反帝反封建反官僚资本主义的革命。

## Key Concepts
- **歼灭战**：消灭敌有生力量，而非赶跑/占领。
- **十大军事原则**：毛泽东军事思想系统化的作战条令。
- **总路线三要素**：领导（无产阶级）+ 动力（人民大众）+ 对象（三座大山）。
- **以战养战**：用缴获补充自己，削弱敌壮大己。

## Mental Models
- **每战必集中倍力**：宁可少打，也要在局部形成绝对优势、全歼而非击溃。
- **打有把握之仗**：无准备无把握不打，避免消耗。
- **夺城不如灭敌**：占领是结果，歼灭敌人有生力量才是根本。

## Anti-patterns
- **平分兵力**：一线摆开、处处设防 → 处处薄弱、被各个击破。
- **击溃战思维**：只赶跑不歼灭 → 敌能再聚、自己虚耗。
- **为地丢人**：为守城而分散兵力、被敌歼灭有生力量。

## Worked Example
"十大原则第一条"落地：面对国民党集中兵力，解放军先打其分散孤立据点、避开嫡系重兵集团，在运动中把敌一节一节吃掉，使敌总量持续下降、我持续上升，终在三大战役中以优势兵力分割围歼。方法示范：不与强敌正面拼消耗，专挑其"弱而散"处下手、打完即并。

## Key Takeaways
1. 基本战法=集中绝对优势、各个全歼敌有生力量。
2. 十大军事原则是可复用的作战清单，根在"集中+歼灭+运动中"。
3. 不打无准备无把握之仗；勇敢要以科学计划为前提。
4. 政治目标明确："打倒蒋介石"与军事原则同步提出。
5. 总路线三要素（领导/动力/对象）是革命方略的总纲。
