# 毛泽东视角技能 · MaoOS v6.0

> 用毛泽东的思考框架分析问题、做决策。基于《毛泽东选集》（五卷）与《毛泽东传》（逄先知、金冲及，六册 79 节）构建的思维框架技能。

## 这是什么

一个 WorkBuddy / Codex 技能（skill），将毛泽东两部权威著作中的思想方法提炼为 **11 个心智模型** 与 **12 个主题章节**，用于：

- 矛盾分析、抓主要矛盾与两类矛盾定性
- 实事求是、调查研究的决策方法
- 群众路线、统一战线、持久战等以弱胜强战略推演
- 组织与领导方法设计（党委会十二条、弹钢琴、胸中有数）
- **风险预警**：31 条反面清单 + 失效模式分析（v5.0 新增）
- 模仿毛泽东文风写作（**显式标注为风格模拟，非史实引用**）

### v5.0 的三个核心改进

| 改进 | 解决的问题 |
|---|---|
| **边界下沉到模型级** | 11 个模型各配「B · 边界与盲点」+「失效信号」，全局失败分支降级为兜底 → 根治输出模板化 |
| **引用三态 + 版本边界** | 已核验 / 待核 / 不在语料，以索引为唯一裁决依据；第五卷（1977 年版）不混同引用 |
| **警示优先** | 决策参谋场景先呈现反面警示——"反面提醒往往比正面主张更救命" |

## 使用方式

作为 WorkBuddy / Codex 技能加载。触发词见 `SKILL.md` frontmatter（群众路线、持久战、统一战线、农村包围城市、集中优势兵力、两个务必、跳出周期率、十大军事原则、毛泽东视角、毛主席怎么说、MaoOS）。

> 触发词只收**高特异性**词；"主要矛盾""调查研究""实事求是"等通用词交由 description 语义匹配兜底，避免误触发。

技能内置 **Step 0 分流 + 四步工作流**，请按序执行：

**Step 0 · 分流** — 先判任务类型：

- **A 分析型**（"怎么分析 / 怎么看"）→ 走下方第 1–4 步。
- **B 文风型**（"毛主席怎么说 / 仿毛体写"）→ 直通 `heuristics.md` 表达风格 DNA + `research/03` 语录库（291 行，带可信度分级），**输出须标注"风格模拟，非史实引用"**。

A 型路径：

1. **定性** — 用路由表定位对应章节（m01–m12），不要一次加载全部（**加载预算 ≤350 行/会话**）。
2. **取法** — 从 `core-models.md` 选 1–2 个心智模型，**连其 B 栏（边界与盲点/失效信号）一并读入**。
3. **落锤** — 每条判断须带「所用模型 + 著作出处」；**决策参谋类场景先查 `warnings.md` 呈现警示**（警示优先）。
4. **核出处**（不可跳过）— 引用前查索引，按 **【已核验】/【待核】/【不在语料】** 三态标注；状态以索引为唯一裁决依据。
5. **自检** — 按序：所选模型的 B 栏 → `warnings.md` → 兜底分支 → 反模式与诚实边界。未通过则回第 2 步换模型。
