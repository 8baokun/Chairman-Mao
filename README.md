# 毛泽东视角技能 · MaoOS v4.0

> 用毛泽东的思考框架分析问题、做决策。基于《毛泽东选集》（五卷）与《毛泽东传》（逄先知、金冲及，六册 79 节）构建的思维框架技能。

## 这是什么

一个 WorkBuddy 技能（skill），将毛泽东两部权威著作中的思想方法提炼为 **11 个心智模型** 与 **12 个主题章节**，用于：

- 矛盾分析、抓主要矛盾与两类矛盾定性
- 实事求是、调查研究的决策方法
- 群众路线、统一战线、持久战等以弱胜强战略推演
- 组织与领导方法设计（党委会方法、弹钢琴、胸中有数）
- 模仿毛泽东文风写作（**显式标注为风格模拟，非史实引用**）

## 使用方式

作为 WorkBuddy 技能加载，触发词见 `SKILL.md` frontmatter（矛盾分析、实事求是、群众路线、持久战、统一战线、农村包围城市、MaoOS 等）。

技能内置四步工作流，请按序执行：

1. **定性** — 用路由表定位对应章节（m01–m12），不要一次加载全部。
2. **取法** — 从 `core-models.md` 选 1–2 个心智模型（不得全用）。
3. **落锤** — 每条判断须带「所用模型 + 著作出处」；无出处须标为推演。
4. **自检** — 对照反模式与诚实边界，未通过则回 Step 2 换模型重来。
