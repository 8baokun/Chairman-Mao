# m07 · 统一战线（1925–1949）

> **双源**：【选集】《论政策》《目前抗日统一战线中的策略问题》《论联合政府》· 【传记】抗日民族统一战线（1935–1937）、全民族抗战（1937–1945）、五湖四海（1949）

## Core Idea
"团结谁、孤立谁"是把矛盾分析用于力量配置的总法。三句话策略：**发展进步势力、争取中间势力、孤立顽固势力**。关键不在基本盘，而在**中间势力的归向**；而联合的前提是**独立自主**——"以斗争求团结则团结存，以退让求团结则团结亡"。

## Frameworks Introduced

### 一、统一战线·三问起点
"谁是我们的敌人？谁是我们的朋友？这个问题是革命的首要问题。"

| 类别 | 构成 | 策略 |
|------|------|------|
| **依靠** | 工人、农民 | 基本盘 |
| **争取** | 小资产阶级、民族资产阶级等中间势力 | 重点争取（决定胜负的关键变量） |
| **孤立** | 主要敌人及其顽固派 | 分化、孤立 |

### 二、三句话策略
1. **发展进步势力**
2. **争取中间势力**
3. **孤立顽固势力**

### 三、又联合又斗争 + 独立自主
- **又联合又斗争**：以斗争求团结则团结存，以退让求团结则团结亡。
- **独立自主**：统一战线中保持政治上组织上的独立，不似奴才。
- 反对两种极端：对国民党"只团结不斗争"或"只斗争不团结"。

### 四、同盟军动态管理
- **依时期变敌友**：抗战时民族矛盾为主、资产阶级可联合；解放战争时阶级矛盾为主、孤立官僚资产阶级。
- 经络：把"反蒋"转为"逼蒋抗日"、和平解决西安事变、改红军为八路军新四军、实行减租减息以团结地主抗日——但坚持党在统一战线中的独立自主。

### 五、五湖四海（执政后最高形态）
- 组建中央人民政府时"共产党人和进步人士一半一半好"。
- 对起义将领"有职有权"（傅作义自己挑副部长；每月给程潜五万斤小米补贴，因"程潜应酬多，开销大"）。
- "搞统一战线哪能怕麻烦"；"手掌是肉手背是肉，不能有厚薄"。

## Key Concepts
- **中间势力**：可争取可不争取、决定胜负的关键变量，须重点争取。
- **又联合又斗争**：联合中不丧独立、斗争中不破联合。
- **独立自主**：联盟中不失自我，不为联合出卖原则。
- **三大法宝**：统一战线、武装斗争、党的建设（详见 m06）。

## Mental Models
- **先列敌友我三栏**：任何博弈先排清"靠谁、争谁、孤立谁"。
- **重点争中间**：胜负常不在基本盘，而在中间势力的归向。
- **以斗保联**：想在联盟里不被吃，就得敢斗争、善退让有度。
- **包下来、给出路**：对旧人员"都包起来"，减少社会震荡、广结人心。

## Anti-patterns
- **关门主义**：只要纯、不要盟，把中间势力推给敌人；对民主党派"有厚薄"即易生官僚主义。
- **投降主义**：为联合放弃原则、丧失独立。
- **轻视群众**：以为少数精英能包办，脱离力量源泉。
- **关门主义/投降主义两端**：只团结或只斗争都错，正确态度是"既不是只有团结，也不是只有斗争"。

## Worked Example
**双源对读**：
- **【选集】《论政策》**给出原则："既不是一切联合否认斗争，也不是一切斗争否认联合，而是综合联合和斗争两方面的政策。"
- **【传记】抗日民族统一战线（1935–37）**给出操作：民族矛盾上升为主要矛盾，毛泽东及时调整——把"反蒋"转为"逼蒋抗日"、和平解决西安事变、改红军为八路军新四军、实行减租减息以团结地主抗日，但坚持党在统一战线中的独立自主。
- **【传记】抗战期总方针两面**（1937.7.14）："一面促成蒋氏建立全国抗战之最后决心；一面自己真正地准备一切抗日救亡步骤；并同南京一道去做。"

**方法示范**：依主要矛盾变化重组敌友，联合中保独立，是"又联合又斗争"的范本。

## Key Takeaways
1. 革命/任何策略首要问题是分清敌、友、我。
2. 统一战线三句：发展进步、争取中间、孤立顽固。
3. 又联合又斗争，以斗争求团结；联合中保独立。
4. 敌友随主要矛盾变化而变，须动态调整联盟。
5. 执政后统一战线的形态是"五湖四海、有职有权"。
