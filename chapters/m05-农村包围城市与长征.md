# m05 · 农村包围城市·武装割据·长征（1927–1937）

> **双源**：【选集】《中国的红色政权为什么能够存在？》《星星之火，可以燎原》· 【传记】武装割据·长征·遵义会议（1927–1937）

## Core Idea
大革命失败后，毛泽东走出"农村包围城市"的独立道路：在敌人统治薄弱处建根据地生根；身处逆境时不硬拚，而是**一个一个做工作争取大多数**，最终在遵义会议实现"走自己的路"的转折。这是他后来反复使用的**危机领导范式**。

## Frameworks Introduced

### 一、【选集】工农武装割据：红色政权存在的五条件
1. 帝国主义间接统治、经济落后、发展不平衡
2. 经过民主革命影响的群众
3. 全国革命形势向前发展
4. 有相当力量的正式红军
5. 共产党组织的有力量和政策不错误

- **三位一体**：武装斗争 + 土地革命 + 根据地建设。
- **星星之火，可以燎原**（1930 年给林彪回信）：用"星火→燎原"否定"红旗到底打得多久"的悲观，论证革命高潮的必然性（不是"可望不可即"）。

### 二、【传记】在孤立中"一个一个做工作"争取大多数
- 长征路上毛泽东同王稼祥、张闻天行军议论，逐一说服，促成遵义会议转折。
- 会后感慨："办什么事都要有个大多数啊！"

### 三、【传记】独立自主解决组织问题
- **遵义会议（1935）**：依民主集中制，结束王明"左"倾教条主义四年统治，确立毛泽东在党中央和红军中的领导地位；"走自己的路"，挽救了党和红军。

## Key Concepts
- **农村包围城市**：中心城市暴动走不通时，转向敌人薄弱、自己能扎根的广阔乡村积蓄力量。
- **古田会议**（1929）：解决党内思想建设与军队建设根本问题。
- **五次反"围剿"失败**：1931 赣南会议到 1934 长征前，毛泽东被批为"狭隘经验论""富农路线""右倾机会主义"，甚至被剥夺工作权利。
- **《孙子兵法》插曲**：毛泽东自述当时只看过《三国演义》，并未看过《孙子兵法》，被凯丰"照两本书打仗"的指责逼得后来才翻了《孙子兵法》——反对本本主义的注脚。
- **政治路线确定之后，干部就是决定的因素**。

## Mental Models
- **星星之火可以燎原**：弱小时看趋势与生根能力，不看来势汹汹——处于低谷但方向对，先扎根再燎原。
- **在薄弱处建根据地**：正面强攻不成，转去对手最弱、自己最能生长的缝隙立脚。
- **逆境淬炼**：被孤立的痛苦磨练让他"更加沉着、练达，思想更加缜密、周到，特别是更善于团结人"。
- **办什么事都要有个大多数**：身处少数时，不硬拚，而是私下沟通、让正确意见被多数接受。

## Anti-patterns
- **本本主义 / 照书本打仗**：把《三国演义》《孙子兵法》当教条，脱离中国实际必败（王明路线即其极端）。
- **残酷斗争、无情打击**：来自党内的"左"倾打击会摧毁正确力量；正确做法是严肃批评又热情团结。
- **悲观主义（红旗打多久）**：只看眼前弱小，不懂矛盾转化与高潮必然 → 丧失方向。
- **忽视大多数**：只靠少数精英硬干，缺乏同盟与群众基础。

## Worked Example
**双源对读**：1930 年《星星之火，可以燎原》在理论上论证"小块红色政权能够长期存在"；1934–35 年的长征则是对这一判断最残酷的检验与最生动的印证——长征出发前毛泽东已被排斥出核心、"弄到于都去搞调查研究"，长征路上他与王稼祥、张闻天同住同行，一路讲反五次"围剿"军事领导错误，逐渐"在政治局内开始了反对李德、博古的斗争"。王稼祥回忆："毛泽东同志开始对我们解释……以马列主义普遍真理和中国革命实践相结合的道理教导我，促使我能够向毛主席商谈召开遵义会议的意见。"遵义会议最终依民主集中制独立自主改组领导。

**方法示范**：这是"在孤立中靠一对一说服争取多数"的范本——**选集给出战略判断，传记给出争取多数的战术**。

## Key Takeaways
1. 中心城市路线走不通时，转向农村根据地积蓄力量，是务实的战略转移而非退却。
2. 弱小时看生根能力而非眼前声势；"星星之火"靠"质"的生长。
3. 身处逆境不硬拚，用调查与耐心的私下沟通争取多数，方能实现转折。
4. 独立自主（不照搬苏联/本本）是遵义会议最宝贵的遗产。
5. 对犯错的同志严肃又团结，才能不重演"残酷斗争"的内伤。
