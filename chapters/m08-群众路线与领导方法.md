# m08 · 群众路线·领导方法（1927–1945）

> **双源**：【选集】《关于领导方法的若干问题》（1943）、《为人民服务》（1944）、《论联合政府》（1945）· 【传记】《湖南农民运动考察报告》（1927）、五大群众运动实践

## Core Idea
"靠谁干"的答案只有一个：**人民**——"人民，只有人民，才是创造世界历史的动力"。但群众路线不是口号，毛泽东把它写成可操作公式：**从群众中来，到群众中去**——把分散无系统的意见集中起来研究成系统，再回到群众中坚持下去、见之于行动，在行动中考验，如此无限循环。

## Frameworks Introduced

### 一、领导方法公式·两个结合（《关于领导方法的若干问题》）
- **一般号召与个别指导相结合**：先普遍号召，再抓试点突破、取得经验、推广全局。
- **领导骨干与广大群众相结合**：把积极分子组成领导核心，团结中坚、带动中间。
- **基本公式**："将群众的意见（分散无系统）集中起来（研究成系统），又到群众中坚持下去、见之于行动，在行动中考验；再从群众中集中，再坚持下去"——即**从群众中来，到群众中去**的无限循环。

### 二、抓两头带中间
- 抓先进典型与落后典型，带动中间大多数。

### 三、为人民服务·宗旨四句（1944）
1. 我们的队伍完全为着解放人民、彻底地为人民的利益工作。
2. 人固有一死，"或重于泰山，或轻于鸿毛"。
3. 为人民的利益坚持好的、为人民的利益改正错的（批评自我批评的落脚点）。
4. 互相爱护、关心、帮助。

### 四、三大作风（《论联合政府》，区别于其他政党的标志）
1. **理论和实践相结合**的作风
2. **和人民群众紧密地联系在一起**的作风
3. **自我批评**的作风

- 政治路线：放手发动群众、壮大人民力量，在我党领导下打败侵略者、解放全中国。

## Key Concepts
- **从群众中来，到群众中去**：领导认识来自群众、回到群众检验。
- **一般号召与个别指导**：先动全局、再抓试点、后推广。
- **三大作风**：理论联系实际、密切联系群众、自我批评。
- **宗旨**：共产党及其军队的存在理由 = 为人民服务。
- **民众的大联合**：《湘江评论》（1919）指出"民众联合的力量最强"。

## Mental Models
- **集中—坚持循环**：凡推行政策，先下沉收集分散意见 → 研究成方案 → 回群众试行 → 再收集修正，循环上升。
- **先试点后铺开**：新举措抓一两个点取得经验，再一般号召全面推。
- **用"为谁"校准一切**：判断一项工作对错，回到"是否人民利益"这一宗旨尺。
- **到农民中找主力**：当城市与上层路线受挫，转向最广大的底层。

## Anti-patterns
- **命令主义 / 尾巴主义**：前者强迫群众超越觉悟，后者落后于群众要求——二者都脱离"从群众中来"。
- **只有号召没有指导**：只发文件不抓试点，政策落不了地。
- **忘宗旨而谋私利**：组织/个人脱离"为人民服务"标尺即变质。
- **轻视群众**：以为少数精英能包办，脱离力量源泉。

## Worked Example
**双源对读**：
- **【选集】"一般号召与个别指导相结合"**：要推广某政策，先向全区发出号召（一般），同时亲自在一个乡/连队蹲点做出样子、找出具体办法（个别指导），再把经验写成指示推广。避免"文件满天飞、下面不会做"。
- **【传记】"包下来、给出路"**（执政期）：对国民党千万党政军人员"都包起来"，减少社会震荡、广结人心；黄炎培反映征粮偏差，毛泽东即令"有则说有，无则说无，是则是，非则非"实地核查。

**方法示范**：用试点把抽象号召转成可复制做法；对群众的反映要实地核查而非文牍应付。

## Key Takeaways
1. 领导方法 = 两个结合 + 从群众中来到群众中去。
2. 任何政策先试点取经、再一般号召，避免空转。
3. 宗旨是尺：一切工作以"人民利益"校准。
4. 三大作风是政党成色标志：理论联系实际 + 联系群众 + 自我批评。
5. 批评与自我批评落脚在"为人民的利益改正错的"。
