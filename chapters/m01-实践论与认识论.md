# m01 · 实践论与认识论（1893–1937）

> **双源**：【选集】《实践论》（1937）· 【传记】早年与求学（1893–1918）

## Core Idea
认识不是从书里来的，是从"下场干过"里来的，并且要回到实践中才验得准。毛泽东在成为理论家之前先是个"自学—亲试—批注"的实践者：退学自修、自编体操亲身试验、读原典做批注——这套习惯二十年后被他提炼成《实践论》。**先有实践之"行"，才有认识之"知"；知行循环，螺旋上升。**

## ⚠️ 本章失效边界（Step 4 自检用）

1. **代价不可逆的领域**（重大不可逆决策、安全、法律定性）——「干中学」承受不起试错成本，须先建模推演再下场，不能拿实践当唯一校验。
2. **认识对象无法被实践触及**（纯数学、已发生的历史、他人内心）——实践检验不适用，此时只能用逻辑与证据链。
3. **把「试过一次」当「已验证」**——单次实践不等于真理；认识公式是「实践—认识—再实践」的**循环**，止于第一轮即是经验主义。
4. **以「我还不够懂」为名无限推迟行动**——这是本模型的反向失效：知行循环要求在下场中求真知，等待本身就是失职。

## Frameworks Introduced

### 【选集】《实践论》· 认识两阶段
- **感性认识**（感觉、印象）→ **理性认识**（概念、判断、推理）。理性依赖感性，二者统一于实践。
- **认识总公式**：实践—认识—再实践—再认识，循环往复、螺旋上升。
- **真理标准**：认识之是否真理，"只有在实践中才能得到证明"。
- **反对三种错**：唯心论的先验论、旧唯物论的直观反映论、教条主义（只读书不实践）。

### 【传记】早年"读原典 + 亲身试 + 自批注"三合一自学法
- 断然从湖南全省高等中学校退学，寄居湘乡会馆，每天步行三里到定王台省立图书馆自学。
- 读《御批历代通鉴辑览》一百一十六卷后更信"在校读书不如自学"。
- 《体育之研究》（1917，署名"二十八画生"）不只立论，还**自编体操并亲身试验**：日光浴、风浴、雨浴、冷水浴、游泳、登山、露宿、长途跋涉、拳术。
- 读泡尔生《伦理学原理》用陆王"心即理"视角做批注——读完、试过、批过，才算自己的。
- 同期常与蔡和森、张昆弟讨论宋明理学，研读朱熹《近思录》《四书集注》《朱子语类》，再以陆王"心即理"反批泡尔生——**先入乎其内、再出乎其外**。

## Key Concepts
- **感性 / 理性认识**：认识的两级，不能停在任一级。
- **实事求是**：'实事'是客观事物，'是'是内部规律，'求'是研究（详见 m03）。
- **有的放矢**：'的'是靶（实际问题），'矢'是理论（马克思主义）；无的放矢与有矢无的皆错。
- **二十八画生**：毛泽东 1917 年发表于《新青年》的署名（"毛泽东"三字繁体共二十八画）。
- **自我教育**：认定方向就敢采取惊世骇俗的行动，自建学习系统而非被动接受课程。

## Mental Models
- **认识先下场再做结论**：没干过、没验证过的只是假设，不是真理。
- **把图书馆当军校**：资源受限时，用系统性自读 + 亲身试验替代被动听课。
- **思想是练出来的**：体育、劳作、社会调查都是淬炼意志的手段，不只求知识。

## Anti-patterns
- **教条主义（本本出发）**：从书本/上级指示出发而非从实际出发（《实践论》重点批）。
- **经验主义（只感性不上升）**：停留于零散感觉，不概括为理性认识。
- **只读不炼**：只吸收知识而不以体魄、实践、组织转化，易成空谈。毛泽东早年即反对"程朱哲学，没有气，没有长角"。
- **依赖现成答案**：把学校课程、权威结论当终点，丧失独立判断。

## Worked Example
**双源对读**：1937 年《实践论》写出"实践—认识—再实践—再认识"的公式；而在二十年前的湖南一师与定王台图书馆，青年毛泽东已经在用这个公式——他读《近思录》《朱子语类》是"读原典"，自编冷水浴日光浴体操是"亲身试"，在泡尔生《伦理学原理》上写下批注是"自求证"。**传记印证了选集**：《实践论》不是书斋产物，是他自学与革命二十年的方法总结。

## Key Takeaways
1. 认识来源于实践，最终靠实践检验；书是箭，问题是靶。
2. 感性必须上升到理性，理性必须回到实践验证。
3. 真正的自主学习是"自定课题、自排体系、自求证"。
4. 体魄与意志是长期认识的底层资源，毛泽东一生坚持冷水浴、游泳。
5. "读原典 + 亲试 + 批注"是个人层面可复制的实践—认识循环。
