# m09 · 整风·党建·文风（1941–1945）

> **双源**：【选集】《改造我们的学习》（1941）、《整顿党的作风》（1942）、《反对党八股》（1942）· 【传记】延安整风（1942 起）、七大（1945）

## Core Idea
延安整风是"建设党"这一法宝的内部工程：用《改造我们的学习》立标准（实事求是、有的放矢），用《整顿党的作风》定方针（惩前毖后、治病救人），用《反对党八股》清文风。**目标只有一个——让全党学会"用马克思主义之矢，射中国革命之的"。** 到 1945 年七大，实事求是、群众路线、独立自主被概括为"毛泽东思想的活的灵魂"三个基本点。

## ⚠️ 本章失效边界（Step 4 自检用）

1. **「惩前毖后、治病救人」无限上纲**——历史教训：整风一旦越出思想范畴转为组织清算，即滑向扩大化（见 m12）。
2. **文风自检变成格式审查**——只查党八股的外在形式、不查是否真分析了问题，是新的形式主义，与本意南辕北辙。
3. **把思想分歧当作错误来整**——整风对象是主观主义、宗派主义、党八股，不是不同意见；混同会扼杀组织活力。
4. **无调查基础的批评**——批评须建立在事实上，否则「治病救人」变成整人工具。

## Frameworks Introduced

### 一、《改造我们的学习》· 实事求是三要点
- **有的放矢**：'的'（中国革命实际）须先调查研究弄清，'矢'（理论）才射得准。
- **系统周密 vs 粗枝大叶**：反对"闭塞眼睛捉麻雀""瞎子摸鱼"式研究。
- 明确给出"实事求是"定义，把党的作风钉在"从实际出发"。

### 二、《整顿党的作风》· 三大整顿 + 一个方针
| 整顿对象 | 反对什么 |
|---------|---------|
| **学风**（中心） | 反对**主观主义**——主观主义是党风文风的根 |
| **党风** | 反对**宗派主义**（闹独立性、山头主义） |
| **文风** | 反对**党八股** |

- **方针：惩前毖后，治病救人**——从团结愿望出发，经批评斗争，到新的团结。

### 三、《反对党八股》· 八条罪状（文风负面自检清单）
1. 空话连篇，言之无物（懒婆娘裹脚布）
2. 装腔作势，借以吓人
3. 无的放矢，不看对象
4. 语言无味，像个瘪三
5. 甲乙丙丁，开中药铺（不提出问题、不分析、只罗列）
6. 不负责任，到处害人
7. 流毒全党，妨害革命
8. 传播出去，祸国殃民

### 四、【传记】七大与毛泽东思想（1945）
- 七大确立毛泽东思想为党的指导思想。
- **活的灵魂三个基本点**：实事求是、群众路线、独立自主。
- 整风使全党在"不左不右"的实事求是路线上达成共识（思想建党）。

## Key Concepts
- **主观主义**：不从实际出发的作风，是党内"最坏的一种思想"。
- **惩前毖后，治病救人**：处理错误/同志的方针，非惩办主义。
- **党八股**：公式化、空话、无对象的文章/讲话，是主观主义的表现形式。
- **学风**：对待马克思主义的态度，整风的中心。
- **思想建党**：整风统一全党思想，是组织与思想建设的根本一招。

## Mental Models
- **先定"的"再找"矢"**：动手写/决策前先问"我要解决的具体问题是什么"，再选理论/方法。
- **八条自检文风**：写完讲话/文件逐条对照八条罪状，命中即改。
- **治病救人而非一棍子打死**：纠正人的错误从"希望其好"出发，给改正出路。

## Anti-patterns
- **主观主义**：理论脱离实际，用一般结论套具体（整风头号敌人）。
- **开中药铺（甲乙丙丁）**：只堆砌条目不分析，看似全面实则不解决问题。
- **装腔作势吓人**：用大词压人，回避真论证。
- **党八股**：空话连篇、不解决问题的文风，整风明令反对。

## Worked Example
**双源对读**：
- **【选集】反对党八股"第五条"**：有人写文章列甲、乙、丙、丁、子、丑、寅、卯一大串，却"不提出问题，不分析问题，不解决问题"。毛泽东讥为"开中药铺"。**方法示范**：文章/方案的价值在"提出问题—分析—解决"的主线，罗列条目是形式主义的遮羞布。
- **【传记】整风的成效**：1942 年起反对主观主义、宗派主义、党八股，"惩前毖后，治病救人"，统一全党思想；到 1945 年七大，实事求是、群众路线、独立自主被概括为"毛泽东思想的活的灵魂"。**印证**：整风不是整人，是把"实事求是"从个人方法变成全党方法。

## Key Takeaways
1. 改造学习 = 立"有的放矢"：先弄清实际问题，理论才用得上。
2. 整风中心反主观主义；方针是惩前毖后、治病救人。
3. 党八股八条是文风红线，写作讲话先逐条自查。
4. 学风正，党风文风才正——作风问题根子在"是否从实际出发"。
5. 整风统一思想、七大确立实事求是，是组织与思想建设的根本一招。
6. 对人纠错要给"出路"，从团结出发回到团结。
