# m03 · 实事求是·调查研究（1927–1941）

> **双源**：【选集】《反对本本主义》（1930）、《改造我们的学习》（1941）· 【传记】《湖南农民运动考察报告》（1927）、寻乌调查（1930）

## Core Idea
"实事求是"是毛泽东思想的精髓，而它的**操作入口是调查研究**。链路是"承认事实（实事）→ 研究规律（是）→ 主动去求（求）→ 回到实践检验"。他本人是这条链路最彻底的践行者：为回应一句指责就下乡 32 天，为弄清一项政策就盘清一城一县的店铺与阶级。**没有调查就没有发言权；情况明才能决心大。**

## ⚠️ 本章失效边界（Step 4 自检用）

1. **调查是为了印证已有结论**（带着结论去找材料）——这比不调查更危险，因为它会给偏见披上实证外衣。
2. **信息本就不可得**（对方刻意隐瞒、黑箱、数据不存在）——调查方法失效，正确做法是承认信息边界并标注，而非编造「调研结果」。
3. **时间窗口极短**——32 天式蹲点来不及；此时先用最小可行验证决断，**事后仍须补齐调查**。
4. **把「调查过」等同于「情况明」**——材料必须过「去伪存真、由此及彼、由表及里」，未经加工的原始材料等于没调查。

## Frameworks Introduced

### 一、实事求是三要素
| 要素 | 含义 |
|------|------|
| **实事** | 客观存在的一切事物（先承认事实，不凭愿望） |
| **是** | 客观事物的内部联系，即规律性 |
| **求** | 我们去研究（主动找规律，不坐等） |

### 二、调查研究七法（《反对本本主义》+《农村调查序言》）
1. **开调查会**（每次三五人至七八人，找深切了解情况的）
2. **亲自出马**（凡担负领导责任者必须自己调查，不能假手于人）
3. **典型调查——"解剖麻雀"**（抓一个典型弄清一类）
4. **蹲点深入基层、甘当小学生**
5. **口问手写、亲记亲算**
6. **穷根究底、不求表面**
7. **旁证对比、判别真伪**（去粗取精、去伪存真、由此及彼、由表及里）

### 三、有的放矢（《改造我们的学习》）
- '的'（中国革命实际）须先调查研究弄清，'矢'（理论）才射得准。
- 反对"闭塞眼睛捉麻雀""瞎子摸鱼"式研究，要求系统周密。
- **调查—决策—再调查循环**：情况明 → 决心大 → 方法对；执行中再调查修正。

### 四、反对本本主义三句
- "没有调查，没有发言权。"
- "调查就像'十月怀胎'，解决问题就像'一朝分娩'。"
- "中国革命斗争的胜利要靠中国同志了解中国情况。"

## Key Concepts
- **本本主义**：唯书唯上、不调查，教条主义别名。
- **解剖麻雀**：通过典型弄清一般，调查研究的基本术。
- **十六字诀**：去粗取精、去伪存真、由此及彼、由表及里。
- **情况明才能决心大**：调查是决策前提，不明则乱。
- **主观主义**：不从实际出发的作风，是党内"最坏的一种思想"。

## Mental Models
- **先沉下去再开口**：任何判断前先问"我调查过吗"，没调查就是本本。
- **解剖一只麻雀**：不用普查全局，抓一个典型深挖即可类推一类。
- **用十六字诀炼材料**：拿到一堆材料先去伪存真、由表及里再下结论。
- **先定"的"再找"矢"**：动手写/决策前先问"我要解决的具体问题是什么"，再选理论方法。

## Anti-patterns
- **本本主义**：捧书本/文件当真理，不结合本地实际。
- **走马观花**：调查只听汇报、看门面，得假情况。
- **情况不明决心大**：不摸底就拍板，必乱必错。
- **空论而不调查**：对农民"糟得很"的指责，源于未亲见；不调查就下判断必错。

## Worked Example
**双源对读（两场调查，同一方法）**：
- **1927《湖南农民运动考察报告》**：为回应"农运糟得很"的指责，实地走遍湘潭等五县、历时 32 天，列出农民做的**十四件大事**（组建农会、打倒土豪、禁烟赌、办合作社等），断言农民"攻击的形势，简直是急风暴雨，顺之者存，违之者灭"，用事实反驳"糟得很"，提出"矫枉必须过正"。该报告被共产国际俄文、英文版译发，是毛泽东第一篇被介绍到国外的文章。
- **1930 寻乌调查**：为弄清"对待中间阶级"政策，亲自开十几天的调查会，把县城店铺、地主、农民、商人逐一盘清，得出"限制富农、保护中小商人"的具体政策。

**方法示范**：典型调查不是泛泛问，而是把一类人的经济结构"解剖"清楚再定策。**传记印证选集**——"没有调查就没有发言权"不是口号，是 32 天走五县走出来的。

## Key Takeaways
1. 实事求是 = 承认事实 → 找规律 → 指导行动，是全书方法核心。
2. 调查七法：调查会、亲自出马、解剖麻雀、蹲点、口问手写、穷根究底、旁证对比。
3. 没有调查就没有发言权；本本是教条不是真理。
4. 材料先过十六字诀（去伪存真、由表及里）再结论。
5. 重大主张必须用实地调查支撑，方能经得起反驳与国际传播。
