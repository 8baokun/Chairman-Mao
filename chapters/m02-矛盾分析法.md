# m02 · 矛盾分析法（1937–1957）

> **双源**：【选集】《矛盾论》（1937）、《关于正确处理人民内部矛盾的问题》（1957）

## Core Idea
矛盾分析是毛泽东全部方法的**总开关**。任何事物都是对立统一的矛盾体，发展的根本原因在内部矛盾性而非外部。操作上分两步：**先用《矛盾论》六层看清事物内部，再区分"敌我"与"人民内部"两类矛盾、给出不同解法**。任何复杂局面都先过这张清单。

## ⚠️ 本章失效边界（Step 4 自检用）

1. **矛盾越找越多、始终定不出主次**——已在二元对立中空转，应立即停止继续找矛盾，回到「用全力找出主要矛盾」这一步。
2. **人际关系与情感领域**——不是所有分歧都是「矛盾」；强行定性会把可调和的关系逼成对抗。
3. **需要多方长期共处而非「解决掉一方」的场景**——矛盾分析预设了「解决」，而有些局面只能共存与制衡。
4. **把「矛盾的主要方面」当固定属性**——主次会随条件转化，须定期重估，否则一次定性管到底必然失真。

## Frameworks Introduced

### 一、矛盾论六层分析法（通用操作清单）
1. **判宇宙观**：用联系/发展/矛盾的观点，不用孤立静止的（唯物辩证 vs 形而上学）。
2. **找普遍性**：矛盾存在于一切过程始终（绝对性）。
3. **辨特殊性**：不同质的矛盾用不同质的方法解决（相对性，调查研究的根据）。
4. **抓主要矛盾与矛盾主要方面**：复杂过程全力找主要矛盾；矛盾两方面分主次，决定事物性质。
5. **看同一性与斗争性**：同中有异、异中有同；同一是相对的、斗争是绝对的；在一定条件下相互转化。
6. **定对抗形式**：对抗是矛盾斗争的一种形式，非一切矛盾都取对抗形式。

### 二、两类矛盾区分（《关于正确处理人民内部矛盾的问题》，1957）
- **敌我矛盾**：对抗性，用专政/镇压解决。
- **人民内部矛盾**：非对抗性，用**民主、说服、教育、"团结—批评—团结"**解决。
- **公式**：从团结的愿望出发，经过批评或斗争，分清是非，在新的基础上达到新的团结。
- **社会主义基本矛盾**：生产关系与生产力、上层建筑与经济基础之间基本适应但局部不适应——靠**制度内自我调节**而非推翻。
- **统筹兼顾、适当安排**：处理人民内部利益矛盾，各得其所。
- **百花齐放、百家争鸣**：艺术科学上"放"与"鸣"，处理人民内部思想矛盾的方法。

## Key Concepts
- **共性个性、绝对相对**：矛盾问题的"精髓"。
- **对抗性 / 非对抗性**：矛盾斗争的两种形式，决定用专政还是民主。
- **团结—批评—团结**：处理人民内部矛盾的固定公式。
- **主要矛盾**："捉住了这个主要矛盾，一切问题就迎刃而解了"。
- **弹钢琴（矛盾统筹）**：统筹主次矛盾，十个指头协调按（详见 m10）。

## Mental Models
- **先分类再定法**：遇到矛盾先问"这是敌我还是人民内部"，对抗性才用强制。
- **抓主要矛盾**：千头万绪先找"牵一发而动全身"的那一个。
- **不同质的矛盾不同质的方法**：拒绝一药治百病。
- **用团结收尾**：人民内部的批评只为"新的团结"，不为打倒人。

## Anti-patterns
- **敌我不分**：把人民内部矛盾当敌我、搞专政扩大化 → 伤害自己人。
- **混用解法**：用强制解决思想问题、用说服解决对抗问题 → 都失败。
- **一刀切**：忽视矛盾特殊性，用一种办法套所有矛盾 → 药不对症。
- **到处找蚂蚁**：晚年把阶级斗争比作"大踏步走路看不见蚂蚁，一蹲下去就看见了"——提醒别忽视矛盾，但也易走向扩大化（详见 m12）。

## Worked Example
**双源对读**：1937 年《矛盾论》用"对症下药"作比——只知"病"不知"殊"，则药不对症：中国革命（半殖民半封建、农民为主）与俄国（帝国主义、工人集中）矛盾性质不同，故道路不同。二十年后《关于正确处理人民内部矛盾的问题》把这一方法推进到执政期：某单位思想分歧，若按敌我处理（开除、批判到底）会压垮积极性；正确做法是阐明"这是人民内部矛盾"，从团结愿望出发开诚布公批评、分清是非，再在新的基础上团结共事。**方法内核一贯**：先判矛盾性质，再选对应解法。

## Key Takeaways
1. 矛盾分析六步是通用清单，复杂问题先逐层过一遍。
2. 矛盾先分"敌我 / 人民内部"，对抗性才专政、非对抗用民主。
3. 人民内部矛盾公式固定为"团结—批评—团结"。
4. 社会主义矛盾可在制度内统筹兼顾、自我调节，不必外求革命。
5. 抓主要矛盾、看主次方面，是"提纲挈领"的操作化。
